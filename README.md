# Code for reproducing _Comparative Stability Analysis of Stress- and Strain-Driven Growth Laws with Neumann boundary conditions_

This is the code for reproducing the figures in the paper: Comparative Stability Analysis of Stress- and Strain-Driven Growth Laws with Neumann boundary conditions

## Install

```bash
python3 -m pip install -r requirements.txt
```

## Reproduce all figures
```bash
bash run_all.sh
```
